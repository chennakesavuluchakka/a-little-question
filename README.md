# Our First Date 💌

A small, responsive first-date proposal website built with plain HTML, CSS and JavaScript. No build tools or backend required.

## Preview locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `our-first-date`).
2. Upload the contents of this folder to the repository root. Make sure `index.html` is at the root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.

## Personalize before publishing
- Edit the note and wording in `index.html`.
- In `js/script.js`, set `contactLink` to a WhatsApp link or other contact URL if you want the “Let's plan it” button to open a direct conversation. If left empty, it opens a prefilled email draft.
- You can change colors and typography in `css/style.css`.

## Notes
- The site is static; no server, database, or API keys are needed.
- GitHub Pages sites are public to anyone with the URL. Avoid adding private information.
- Google Fonts are loaded from Google Fonts; the site still works with fallback fonts if unavailable.
